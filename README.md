# VOLLEY CONTROL

Prova di download autonomo dei calendari FIPAV Como per due squadre: PVI Studio Ottolina U15 e PVI Pinuccè U17.

Avvio con Streamlit: `streamlit run app.py`.

Il pulsante «Aggiorna calendari FIPAV» tenta il download dagli endpoint ufficiali individuati nella precedente analisi e permette di salvare la risposta JSON o il report degli errori. Non dichiara riuscita la lettura se il download fallisce. Prototipo, non app di prenotazione.
